# 更新

Ink Canvas 从 `QiXinia/Ink-Canvas-HEHS` 的 GitHub Releases 获取公开稳定版列表。更新服务不需要 GitHub 登录凭据。列表排除草稿版和预发行版，并选择名称包含 InkCanvas、WinUI、x64 的便携 ZIP。

## 下载验证

更新包必须带有 GitHub Release 提供的 SHA256 digest，或同一 Release 中 `SHA256SUMS.txt` 对应文件名的校验值。下载过程中同时检查发布的文件大小，只有长度与 SHA256 均匹配时才会将 `.partial` 文件移为可安装 ZIP。API、下载内容、超时和校验失败会继续尝试下一个 HTTPS 来源。传输每获得 64 KiB 数据才续期二十秒的进度超时，避免持续返回少量数据的慢连接阻塞切源。

来源顺序为 GitHub、`gh-proxy.com`、`gh-proxy.org`、`ghfast.top`。镜像只代理最初指向 GitHub 的固定仓库 Release/API 地址，返回内容仍经过 JSON 或 SHA256 验证。失败详情写入 Ink Canvas 应用日志。

## 静默安装

“自动检查更新”和“静默更新”启用时，更新器每六小时检查一次。静默更新按设置的起止时间执行，起止时间相同表示全天。安装前还要求画布没有批注和活动笔画，没有打开的白板、文档或其他相关窗口，并且系统输入空闲至少一分钟。条件未满足时保留更新并继续等待。更新失败会在十五分钟后重试。

静默更新开启时，时段外继续等待。静默更新关闭时，自动检查会显示版本说明并等待确认。手动“版本列表”也由用户选择版本和确认。手动安装会保存当前画布和应用设置，然后关闭主程序。

## 文件替换与恢复

便携 ZIP 解压到用户本地应用数据目录下的唯一暂存目录。更新辅助进程位于暂存目录，在确认主进程退出后替换程序文件。已安装的可选模块随主程序更新，未安装的可选模块不会被添加。`Plugins`、`PluginData`、设置、自动保存、`.icink` 文档和其他未列入 Ink Canvas 更新清单的文件会保留。

更新器记录本次托管文件清单，只删除前一次清单中的旧程序文件。正式替换前会备份将被覆盖或删除的文件，并写入回滚日志。若更新进程在替换期间失败或中断，下次运行同一更新计划时先恢复该日志，再重试更新。

包和安装暂存位于 `%LOCALAPPDATA%\InkCanvas\Updates`。更新进度、连接源和错误会显示在设置的版本页面，技术日志位于 `%APPDATA%\InkCanvas\Log.txt`。

## 仓库验收

以 GitHub 仓库发布的 `v3.5.0` 真实 ZIP 在隔离目录执行了完整流程，涵盖版本列表识别、GitHub 下载和 SHA256 校验、GitHub 断连后的镜像列表及 ZIP 下载、ZIP 暂存、外部辅助进程替换、用户插件和 `.icink` 保留，以及更新后程序启动。镜像访问在部分轮次返回 403 或出现 TLS/连接超时，成功轮次的真实包已通过 SHA256 校验。
