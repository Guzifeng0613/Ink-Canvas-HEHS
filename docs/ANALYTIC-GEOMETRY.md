# 解析几何模块

`inkcanvas.analytic-geometry` 是可独立安装的原生 WinUI 3 模块。完整程序包默认包含解析几何、PDF 和屏幕内容跟随模块，独立 ZIP 可解压到程序目录的 `Modules` 后重新启动。模块开关位于“设置 → 模块与插件”。

桌面工具栏和白板工具栏的“更多”均有“解析几何”入口。插件绑定打开时的画布页面，编辑器中的半透明曲线会实时映射到该画布。切页后，点击“使用当前画布 / 所选图形”重新绑定。

## 公式与坐标

| 类型 | 示例 |
| --- | --- |
| 显式函数 | `y=a*x^2+b*x+c`、`x=y^2`、`y=sin(x)` |
| 隐式方程 | `x^2+y^2=25`、`x^2/9-y^2/4=1`、`x*y=1` |
| 参数方程 | `x(t)=a*cos(t)`、`y(t)=b*sin(t)` |
| 极坐标 | `r(t)=a*cos(b*t)`、`r(t)=a*t` |

支持 `a`、`b`、`c` 参数、坐标范围及参数区间。角度使用弧度。`π`、`θ`、全角字符、`²`、`³` 和 `2x` 这样的隐式乘法会规范化。可使用三角及反三角函数、双曲函数、`sqrt`、`abs`、`exp`、`ln`、`log`、`min`、`max`、`pow`、`floor`、`ceil`、`round` 和 `atan2`。`log` 为以 10 为底的对数，幂运算按右结合处理，`-x^2` 表示 `-(x^2)`。

原生公式键盘支持光标移动、退格、数字、变量、运算符和函数。手写页复用项目墨迹输入控件，通过 Windows 本地手写识别器生成可选择候选。需要安装对应 Windows 手写语言包，复杂的二维分式与上下标可以通过公式键盘补全。

预览支持拖动和平移缩放，停止手势后按新的坐标范围重新计算。“插入形状”和“新建图形”始终位于窗口顶部。

## 形状对象

每个图形由带共同来源标识的矢量轮廓构成，保留公式、坐标范围、参数和对象框。单击任意分支会选择整个图形，支持移动、缩放、旋转、克隆、层级、擦除及单步撤销。

选中图形后打开解析几何，或点击“使用当前画布 / 所选图形”，可修改原公式。“更新所选形状”保留该对象的位置与变换。“新建图形”生成独立对象。克隆后的图形使用独立来源标识。

公式数据随 `.icink`、白板存档以及 Ink Canvas PDF 批注保存。未安装解析几何模块时，已保存的矢量图形仍可显示和进行普通选择操作。

## 性能边界

输入变化合并约 110 ms 后在线程池计算。公式编译结果按当前表达式复用，参数变化重用数值委托。旧请求使用取消标记与版本号丢弃。显式、参数和极坐标曲线按显示误差自适应细分，隐式方程使用有界网格、零点验证与轮廓拼接。

单次最多进行 220000 次数值计算，输出最多 32000 个顶点。遇到无效定义、不连续点、不可计算的区域或预算上限时给出反馈，曲线在坐标边界裁切。编辑预览保留独立 GPU 缓存，不写入撤销历史，提交后使用现有形状渲染与选择路径。

## 构建与验证

```powershell
dotnet test tests/InkCanvas.Core.Tests/InkCanvas.Core.Tests.csproj -c Release -p:Platform=x64
.\tools\pack-extension.ps1 -Project src/InkCanvas.Modules.AnalyticGeometry/InkCanvas.Modules.AnalyticGeometry.csproj -Kind Module
.\InkCanvas.exe --geometrycheck=D:\Checks\Geometry
```

`IncludeAnalyticGeometryModule=false` 可构建不携带此模块的主体。运行时检查覆盖原生公式键盘、手写候选、画布实时预览、插入与更新、保存、撤销重做、连续参数变化、切页保护和窗口关闭资源清理。红外屏上的接触形态和端到端延迟需要在目标设备上验收。
